# Portfolio and CV Website

This project is a personal portfolio and CV website designed to showcase my skills, projects, and professional experience. 

## Features

- Home page with an introduction
- About page detailing my background
- Portfolio page showcasing my work
- Contact page for inquiries
- Resume page with my professional experience

## Technologies Used

- HTML
- CSS
- JavaScript

## Installation

To run this project locally, clone the repository and open `index.html` in your web browser.
